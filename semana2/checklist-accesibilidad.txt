1. ¿El formulario tiene un título claro?

2. ¿El formulario explica para qué se usará la información?
Respuesta:Si.Incluye un texto inicial que indica que los datos seran usados para registrar propuestas cuidadanas y contactar al participante 

3. ¿Cada campo tiene un label o etiqueta visible?
Respuesta:Si.Todos los campos como Nombre,correo,telefono y propuesta tienen su etiqueta <label> asociada y visible 

4. ¿El lenguaje usado es sencillo y comprensible?
Respuesta:Si.Se uso lenguaje claro sin tecnisimos,con instrucciones cortas y directas para que cualquier persona ño entienda 

5. ¿El formulario evita pedir datos innecesarios?
Respuesta:Si.Solo solicita datos basicos: nombre,correo y la propuesta.No pide documento,direccion exacta ni información sensible 

6. ¿El campo principal permite escribir una propuesta o mensaje de forma clara?
Respuesta:Si.El campo de "propuesta" es un <textarea> amplio que permite escribir libremente y sin limite restrictivo de caracteres 

7. ¿El formulario incluye una casilla o mensaje de consentimiento?
Respuesta:Si.Se agrego in checkbox con el texto "acepto el tratamiento de mis datos personales" antes del botón enviar 

8. ¿El botón de envío tiene un texto claro?
Respuesta:Si.El botón dice "enviar propuesta" lo que indica claramente la acción que realizará el usuario al hacer clic 

9. ¿La página se puede leer con facilidad?
Respuesta:Si. Se usa un tamaño ee letra legible,buen contraste entre texto y fondo, y los elementos estan espaciados para facilitar la lectura en el celular o computador
