1. ¿El formulario tiene un título claro?

2. ¿El formulario explica para qué se usará la información?

3. ¿Cada campo tiene un label o etiqueta visible?
Respuesta: Si, todos los campos tienen su respectiva etiqueta como nombre, mensaje y contacto.

4. ¿El lenguaje usado es sencillo y comprensible?
Respuesta: Si, el lenjuage del formulario es claro, directo y fácil de entender para los usuarios.

5. ¿El formulario evita pedir datos innecesarios?
Respuesta: Si, este formulario solo pide datos basicos como el nombre del participante y su contacto o correo de forma opcional.

6. ¿El campo principal permite escribir una propuesta o mensaje de forma clara?
Respuesta: Si, ya que esta contiene un área de texto amplia y permite escribir de forma comoda.

7. ¿El formulario incluye una casilla o mensaje de consentimiento?
Respuesta: Si, se incluye una casilla de aceptación para el uso de datos.

8. ¿El botón de envío tiene un texto claro?
Respuesta: Si, el botón dice "Enviar participación", lo cual es claro y específico.

9. ¿La página se puede leer con facilidad?
Respuesta: Si, ya que el texto es claro, el tamaño de letra es adecuado y el fondo claro del formulario con sus borde amarillos permiten una buena lectura.
