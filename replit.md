# Programadores para la Paz – Semana 2 Día 5

## Overview
Static HTML/CSS web project containing a community participation form ("Formulario Participa"), an accessibility checklist, and a responsible verification reflection. Source files live in the `semana2/` directory.

## Project Structure
- `semana2/index.html` – Form page
- `semana2/styles.css` – Styles
- `semana2/checklist-accesibilidad.txt` – Accessibility checklist
- `semana2/reflexion-verificacion.txt` – Verification reflection
- `instrucciones/` – Activity guide
- `README.md` – Activity instructions

## Replit Setup
- Workflow `Start application` runs `python3 -m http.server 5000 --bind 0.0.0.0 --directory semana2` on port 5000 (webview).
- Deployment target: `static`, serving the `semana2/` directory.
